## Location-Level Tools

<Warning>
  `get_listing`, `get_listing_location_status_report`, `create_listing`, `update_listing`, `fix_listing`, and `deactivate_listing` are **location-level tools** — they require a `locationId` parameter.

  Call [`get_child_locations`](/mcp/tools/business/get-child-locations) first to get the list of valid location IDs.
</Warning>

## Tips

- `get_listing_insights` defaults to the last 12 months if no date range is provided.
- `get_listing_category_list` is useful before creating or updating a listing — use it to find the correct category ID for a given platform. Never guess a category.
- `create_listing` and `update_listing` share the same section objects (`businessInfo`, `additionalInfo`, `gmbListing`, …). A section you send **replaces** the stored one, so call `get_listing` first and send complete sections.
- `get_product_listing_list` only returns data if your Google Merchant account is connected in Birdeye.
- After calling `deactivate_listing`, use `fix_listing` or `create_listing` to resume publishing to directories.
