## Tips

- `get_child_locations` is a prerequisite for any location-level tool — call it first to get valid location IDs.
- `get_business_info` returns the top-level account profile (name, address, phone, website).
- `create_business`, `update_business`, `update_business_status` and `delete_business` are **write tools** — confirm the exact target and intent before calling.
- `update_business` requires `emailId`, `phone` and `services` on **every** call — read the current values with `get_business_info` before changing anything else.
- `delete_business` **cannot be undone** and takes child locations with it. If the user only wants to stop using a location, `update_business_status` set to `"inactive"` is reversible and is usually what they mean.
- Resolve a `cardId` with `get_custom_card_details` before calling `update_custom_card` or `delete_custom_card`.
