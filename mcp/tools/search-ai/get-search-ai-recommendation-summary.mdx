title: "Get AI Search Recommendation Summary"

---

```
get_search_ai_recommendation_summary
```

## Description

Returns the complete detail of a single AI Search recommendation: everything in the list item plus step-by-step implementation guidance, why it matters, competitor scores and gaps, competitor insights, and a phased execution plan.

## Parameters

| Parameter | Type | Required | Default | Description |
|---|---|---|---|---|
| `recommendationId` | string | Yes | — | Recommendation `valueId` from [`get_search_ai_recommendations`](/mcp/tools/search-ai/get-search-ai-recommendations) |
| `status` | string | No | — | Recommendation's `recommendationStatus`: `"PENDING"`, `"ACCEPTED"`, `"COMPLETED"`, or `"REJECTED"` |
| `theme` | string | No | — | Recommendation's `theme` |
| `viewReportType` | string | No | — | `"LOCATION_LEVEL"` or `"ACCOUNT_LEVEL"` |

## Example Usage

```
How do I implement my top AI Search recommendation?
```

```
Which competitors are beating me for the pet-friendly apartments recommendation?
```

## Notes

- Call [`get_search_ai_recommendations`](/mcp/tools/search-ai/get-search-ai-recommendations) first and pass the item's `valueId`, `recommendationStatus`, and `theme`.
- `executionPlan` groups `implementationSteps` into phases; follow tasks in `executionOrder`.
