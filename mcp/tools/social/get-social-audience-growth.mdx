---
title: "Get Social Audience Growth"
description: "Track follower growth across social channels with previous-period comparison."
---

```
get_social_audience_growth
```

## Description

Returns follower gains and losses, net audience growth, and total audience across the connected social channels, with the change versus the previous period. The comparison is always made against the previous period of equal length and cannot be customized.

## Parameters

| Parameter | Type | Required | Default | Description |
|---|---|---|---|---|
| `startDate` | string | No | Last 30 days when no period is requested | Start date in `MM/DD/YYYY` format. Provide together with `endDate` |
| `endDate` | string | No | Today when no period is requested | End date in `MM/DD/YYYY` format. Provide together with `startDate` |
| `groupByType` | string | No | Chosen by the API from the range | Bucket size: `day`, `week`, `month`, or `quarter` |
| `socialChannels` | list[string] | No | All channels | Channels to include: `facebook`, `instagram`, `linkedin`, `tiktok` |
| `businessNumbers` | list[integer] | No | All locations | Location IDs to include |

## Example Usage

```
Which social channel is gaining the most followers?
```

## Response Fields

`summary.actual` and `summary.compare` include follower and like gains and losses, `net`, `totalAudience`, and per-channel `channelWiseData`. `dataPoints` provides the same metrics for each time bucket, including per-channel net growth (`fbNetGrowth`, `igNetGrowth`, `lnNetGrowth`, `ttNetGrowth`).

## Notes

- Both `startDate` and `endDate` must be provided to use a custom range; otherwise the last 30 days are used.
