## Tips

- All tools require `businessNumbers` — always call [`get_child_locations`](/mcp/tools/business/get-child-locations) first to get valid values.
- If the user doesn't specify which locations to include, present the available locations and ask them to choose before calling these tools.
- Use the `*_score_benchmark` tools to answer "how do we compare to the industry?", the `*_location_info` tools to answer "which of our locations are improving or declining?", the `*_location_info_rank` tools to surface top/bottom performers, and the `*_over_time` tools to answer "how has this trended?"
- `get_insight_sentiment_category` breaks sentiment down by review category (e.g. Customer Service, Wait Time); `get_insight_reputation_source` breaks reputation down by review source (e.g. Google, Facebook).
